# Flutter Android change log

- Phone-owned history/keyword search, explicitly approved memory CRUD/export, note/tasks/study-attempt persistence, no automatic cross-chat memory or data upload.
- Five requested main destinations and study/file subviews; configurable assistant display name; modest accessible orb and real local-record overview.

- Native picker for selected materials, local text/image preview, unsupported PDF/OCR/vision clearly labeled.
- Local payload-bound single-use device-action ledger, approximate reminders and supported app launches, explicit unknown handling.
- Android16/API36 build priority, automated safety/regression tests and separate native emulator qualification workflow. Actual results and limits belong in FLUTTER_TEST_STATUS.md; roadmap is not an implemented-feature list.
