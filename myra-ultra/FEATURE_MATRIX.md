# MYRA Ultra Android port — feature matrix

This matrix distinguishes the inherited WebView/Chaquopy prototype from the separate native Android increment. A successful build means compilation only; it does not establish installation or runtime behavior.


## Source-derived portrait, orb and live-voice UI slice

`native-android/app/src/main/res/drawable-nodpi/myra_portrait.jpg` is copied byte-for-byte from the upstream prototype asset `prototype/app/src/main/python/myra_termux/assets/myra.jpg`. `SourceVoiceHero` maps the `ui_html.py` `.hero` crop, overlay gradient and source radial gradient color stops, `body.chatting .hero` 158dp compact height, the ≤560dp 120dp override, 84dp orb/0.78 compact scale, and the 8dp-outset animated ring. Idle/listening/thinking/speaking map to source crimson/mint/ember/sky colors and “Orb dabao — MYRA hamesha sunegi” / “Sun rahi hoon…” / “Soch rahi hoon…” / “Bol rahi hoon…” labels; the microphone outline and 1.9/2.4 stroke widths follow source SVG/CSS. Listening and speaking pulse at the source 1.5s cadence; thinking breathes at 1.2s. Android `ValueAnimator.areAnimatorsEnabled()` suppresses these loops when Android reports animator animations disabled; this is narrower than claiming every browser `prefers-reduced-motion` preference is matched. `GeminiLiveSession` maps setup/token/connection, tool-call, audio, interruption and turn-complete events: it stays speaking while queued 24 kHz mono PCM exceeds the source 20ms tail, then returns to listening; reconnect copy follows the source. Queue time is sample-duration estimated; actual AudioTrack output latency is device-specific and unverified. On Home, tapping the idle orb opens Chat; in Chat, the orb and existing mic control share the same permission-gated start/stop operation. The Android Preferences destination now uses a responsive source-shaped bottom sheet: max 560dp width, max 88% available height, fixed header/footer, scrollable body with 18dp field spacing, 48dp minimum action height, and a language results box capped at 30% height. It includes the source API-key/name/language/headphones/chat-clear controls; name is capped at 30 characters, language search matches code/English/native names and prepends Auto — Hinglish before limiting the first 80 results, and Save/Close stage or discard the name/language/barge-in choices. Android-specific Gemini model choice and secure-key removal remain added controls. Auto is now the default and does not force a Gemini text-language instruction; TTS uses Android’s default locale as an approximation, not the prototype’s adaptive web speech. Chat clear uses a confirmation and removes only locally persisted Android chat messages, while upstream clears its in-memory session history. Home/Chat settings now open as a Compose full-window modal over the Android navigation scaffold; the dialog dim amount follows source `#000a`, while the separate bottom-navigation Settings destination remains. Orb press feedback now scales to 0.95 with the source 200ms transform transition and default CSS ease curve. The portrait crop and hero-height transitions follow the source 450ms timing curves, and the hero text explicitly uses Android system sans with source sizes/weight/letter spacing. The native system-bar color and light-status setting now match the source Android wrapper (`#101116`, dark status icons disabled); edge-to-edge insets, platform font metrics and final crop/rendering are still not pixel-matched or visually qualified.

`SourceVoicePresentationTest` locks the source state labels/colors, recognized native session statuses and source reconnect copy, clamp/hero geometry, animation/icon/gradient values and queued-audio speaking→listening timing. Remaining differences include Compose's platform font metrics, visual crop interpolation and system-bar/modal presentation, source adaptive web speech versus Android default-locale TTS in Auto mode, in-memory upstream reset versus confirmation-gated local-history clearing, source server API-key validation versus local encrypted-key storage, and live audio/device latency. These are not pixel/runtime matched. Full-feature parity, live Gemini behavior, Android 16/emulator install/runtime behavior and Redmi 24090RA29I compatibility remain unverified. The included source snapshot has now been published in the Personal-agentic-ai repository with the owner’s authorization. This does not indicate that an APK release exists or has been tested on a device.
